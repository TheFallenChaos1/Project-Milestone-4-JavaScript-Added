# Web-Slinger HQ — Milestone 3

A three-page portfolio site with Spider-Man styling, built for Web Dev 140.

## Files
- `index.html` — home page, advice API, contact form
- `about.html` — about page
- `projects.html` — mission board with filter buttons
- `styles.css` — red/blue theme
- `main.js` — menu, filters, form validation, fetch

## Features
1. **Hamburger menu** — `querySelector` + `addEventListener`, keyboard accessible (Escape closes it)
2. **Form validation** — required fields, on-page errors (no `alert()`), clears as you type
3. **Project filters** — show/hide cards without reloading
4. **Bonus API** — `fetch()` to Advice Slip with error handling

## Deploy
Upload all five files to the root of a GitHub repo, then:
Settings → Pages → Deploy from branch → main → / (root) → Save
